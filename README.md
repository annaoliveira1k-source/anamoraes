# Ana Moraes — Página Profissional

Este repositório contém a página profissional estática desenvolvida para apresentar posicionamento, propósito e presença digital básica.

## Objetivo

Apresentar identidade profissional com foco em:
- Gestão
- Finanças
- Métodos organizacionais
- Apoio a pequenos negócios
- Crescimento sustentável

## Publicação

Este projeto pode ser publicado gratuitamente utilizando GitHub Pages.

Após realizar commit dos arquivos:
1. Acesse Settings
2. Vá até Pages
3. Selecione a branch principal (main)
4. Salve

O site ficará disponível em:
https://SEUUSUARIO.github.io/NOMEDOREPOSITORIO/
